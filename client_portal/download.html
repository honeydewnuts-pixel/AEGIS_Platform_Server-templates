Download AEGIS

The APK is only available after demo signup or a paid subscription. Each download link is single-use and the install binds to one phone.

Paid subscribers

After checkout you receive a one-time download_url. Open it on your phone browser to install. Opening the same link again will fail.

Try demo first

Call POST /api/subscriptions/demo/signup (or use your website form that calls it). You get:

  • account_id + mobile API key
  • one-time APK download link
  • brain / chart analysis for 14 days
  • no live trading until you subscribe

Device lock

On first launch the app registers this phone’s ID. Another phone using the same key is blocked until an operator clears the binding.
